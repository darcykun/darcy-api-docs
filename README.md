# WB THE KID — API Documentation

- [Browse endpoints](./index.html)

- [OpenAPI 3.1](./openapi.json)

This repository contains **only explicitly selected public API metadata**. Backend source code, provider URLs, tokens, GitHub configuration, and upstream responses are not copied.

This site updates automatically from the private backend repository through a GitHub Actions workflow.
